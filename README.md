# Student Records REST API (Spring Boot)

This project implements a RESTful API for managing student records using Spring Boot, Spring Data JPA, and H2 Database.

## Features
- Add new student
- Fetch all students
- Fetch student by ID
- Update student details
- Delete student
- Input validation and exception handling

## Tech Stack
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Lombok
- Postman for testing
